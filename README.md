# Cybersecurity Risk Assessment & Security Monitoring Lab

## Overview

This project simulates a cybersecurity assessment for a small
organization called Arkansas Creative Services.

The project combines cybersecurity risk management with hands-on
Linux security analysis.

## Objectives

- Identify organizational assets
- Identify cybersecurity threats
- Evaluate cybersecurity risks
- Recommend security controls
- Perform a Linux security audit
- Analyze network services
- Document security findings
- Develop an incident response plan
- Create a vulnerability management process

## Technical Assessment

A Bash security audit script was created to collect information
about the Linux system, including:

- Hostname
- Current user
- Operating system
- IP address
- Network connections
- Logged-in users
- Disk usage
- Memory usage
- Recent login activity

An authorized Nmap scan was performed against localhost
(127.0.0.1).

The scan checked the 1,000 most common TCP ports. The host was
reachable, but all 1,000 scanned TCP ports were closed.

## Risk Assessment

The project identifies several common organizational risks:

- Phishing
- Ransomware
- Weak authentication
- Unauthorized access
- Lost or stolen devices
- Unpatched software

Security controls were recommended for each identified risk.

## Incident Response

An incident response scenario was developed covering:

1. Identification
2. Containment
3. Eradication
4. Recovery
5. Lessons Learned
